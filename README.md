# 株ニュース

株式投資まわりのニュースを 1 つの画面に集める、自分用のニュース集約です（投資に限らず、経済・国際・テック・一般も同じ画面で読めます）。
Python の標準ライブラリだけで動きます（追加のインストールは不要）。

## 使い方

`start.bat` をダブルクリック、または:

```bash
python -m stocknews serve --open
```

- 画面は http://127.0.0.1:8770/ 。この PC の中だけに公開されます（外からは見えません）。
- 起動中は 30 分おきに自動で取り直します。画面右上の「更新」で今すぐ取り直せます。
- 1 回だけ取得して書き出すなら `python -m stocknews build`、取得元の一覧は `python -m stocknews sources`。

## 画面でできること

- タブ: すべて / 株式・市況 / 決算・開示 / 経済・政策 / 企業・産業 / 国際 / テック / 一般
  - 「すべて」には、適時開示（件数が多い）を出していません。「決算・開示」タブで見ます（ウォッチ中の会社のものだけ「すべて」にも出ます）。
- 検索（全角・半角、大文字・小文字の違いを無視）、言語（日本語 / English）、未読のみ、要約の表示切替
- **銘柄別**（上の切替）: 登録した銘柄ごとに記事を分けて見ます（下の「銘柄ごとの記事分類」）。
- **ウォッチ**: 銘柄を登録・編集します。項目は開示レーダーの銘柄の記録と同じ形です（名前・コード・英語名・状態（監視中／停止中）・市場・業種・公式サイトと IR 情報の URL・キーワード（日本語・英語）。こちらで別名・除外語も足しています）。Google ニュースでもその名前を検索して集めます。停止中の銘柄は、取得も照合もしません。
- **あとで読む**（☆）・既読の記録は、このブラウザーの中だけに保存されます。
- **取得状況**: 取得元ごとの成功・失敗。止まった配信にすぐ気づけます。
- 同じ話題（別の媒体の同じ記事）は 1 つにまとめ、「同じ話題 ほかN件」で開きます。

## 銘柄ごとの記事分類（開示レーダーの仕組みを、無料の規則だけで）

開示レーダー（kaiji-radar）の「銘柄ごとに記事を振り分け、ノイズを除き、種類と重要度を付ける」仕組みを移したものです。
AI（Gemini）も外部サービスも使わず、通信もしないので、費用はかかりません（`stocknews/stocks.py`）。

1. **関連性**（記事 × 銘柄）: 社名・別名・英語名が見出しにある＝確実／要約だけ・コードだけ・キーワードだけ・検索で当たっただけ＝関連不確実。
   - 銘柄コード（4 桁の数字）は「(7203)」「証券コード 7203」「7203.T」の形のときだけ数える（「1911」が西暦・型番に当たるのを防ぐ）。
   - 英数字の語は前後が英数字なら当たらない（「JT」が「JTB」に当たらない）。
   - 別の銘柄のより長い名前の一部は数えない（「ソフトバンクグループ」の記事は「ソフトバンク」の記事にならない）。
2. **ノイズ除外**: 銘柄ごとの「除外語」（オリックスの野球、ヤマハ発動機の中古品、ソフトバンクのホークスなど）に当たる記事は外します。
   - ただし **保護キーワード**（決算短信・M&A・訴訟・リコール・増配…57 語）がある記事と、**公式の開示（TDnet）** は消さず、関連不確実で残します。
   - 全銘柄共通で、市場調査レポート業者の宣伝記事も外します。
   - 外した記事は、銘柄の画面の「除外した記事（確認用）」に理由つきで残ります。間違いなら除外語を直します。記事の「不要」ボタンから、除外語を足せます。
3. **種類**: 決算 / 業績予想修正 / 配当 / 自己株式 / M&A・TOB / 提携 / 人事 / 株主総会 / 訴訟・行政処分 / 製品・サービス / その他。
4. **重要度**: 最重要 / 重要 / 通常（開示レーダーの規則。公式の開示は既定で「重要」）。

開示レーダーとの違い: 関連性の最終判定に AI を使いません。迷う記事は「関連不確実」で残します。
銘柄は画面の「ウォッチ」で足し引きします（`config/watchlist.json` に保存。このファイルは公開しません）。

## スマホで見る（Cloudflare Pages・合言葉つき）と自動更新（GitHub Actions）

取得済みのデータの写しを Cloudflare Pages に置きます。開くとログイン画面で合言葉を聞かれます。一度入れると、長持ちする Cookie（180 日・使うたびに延びる）が付くので、スマホのホーム画面に入れたアプリでも毎回は聞かれません。合言葉を変えると、前の Cookie は全部使えなくなります。確認用の道具（curl など）は、従来どおり Basic 認証（ユーザー名は何でもよい）でも入れます。

```bash
python -m stocknews publish setup          # 初回だけ: 置き場所の作成・合言葉の登録（.env に鍵が要る）
python -m stocknews publish deploy         # 取得して置き直す（--no-fetch で取得を省く・--only-if-new で新着がなければ置かない）
python -m stocknews publish check          # 合言葉なし=401・正しい合言葉=200・ログイン画面と Cookie を確かめる
python -m stocknews publish password       # 公開先の URL と合言葉を表示する
python -m stocknews publish sync-watchlist # 銘柄リストを GitHub の秘密の変数に送る
```

- 公開先の画面では「更新」と銘柄の編集はできません（PC の画面でだけ）。
- 認証の情報は `.env`（git 管理外）にあります。コードにも画面にも出しません。

### 自動更新（`.github/workflows/update.yml`）

毎時、GitHub Actions がニュースを取り直し、新しい記事があれば置き直します。
このリポジトリは公開（Public）で、公開リポジトリの Actions は分数が無制限・無料です。

- リポジトリに入れるのはコードだけです。記事のデータはコミットせず、実行の中で作って直接置きます。
- 秘密の変数（Settings → Secrets）: `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_PAGES_PROJECT` /
  `WATCHLIST_JSON`（銘柄リスト。`publish sync-watchlist` で送る）/ `DB_KEY`（記事の履歴を暗号化する鍵）。
- 記事の履歴（SQLite）は、`DB_KEY` で暗号化してキャッシュに置きます（公開リポジトリのキャッシュは他人が読める可能性があるため）。
  キャッシュが消えても、履歴が短くなるだけで動き続けます。
- 実行ログも公開されます。銘柄名・公開先の名前・アカウント ID はログに出ないようにしています。
- 60 日間コミットがないと定期実行が止まるため、月 1 回の空コミット（`keepalive.yml`）で止まらないようにしています。

## 取得元

`config/sources.json` に書いてあります（新聞・通信社・経済誌の RSS、日本銀行・金融庁・FRB・ECB・SEC、適時開示 TDnet、Google ニュースの検索）。
追加・削除はこのファイルを編集します。`cat` はカテゴリの既定、`gn` は Google ニュースの検索語です。

- 見出し・出所・短い要約・元記事へのリンクだけを保存します（本文は取りません）。個人で読む用途のため、**このサイトを外に公開しないでください**。
- 適時開示は「決算短信・業績予想の修正・配当・自己株式・TOB・上場廃止…」など株価に影響しやすいものだけ残します（`stocknews/classify.py`）。
- 値動きだけの銘柄・投信ページ（Yahoo!ファイナンスなど）は記事ではないので除きます。
- 記事に日付が無い配信は、取得した時刻を公開時刻として表示してしまうため置いていません。

## 仕組み

```
config/sources.json ─┐
config/watchlist.json ┴→ stocknews/refresh.py（取得・分類・保存） → data/news.db（SQLite・30 日分）
                                  → stocknews/export.py（同じ話題をまとめ、ウォッチを照合） → site/data/news.json
                                  → site/（index.html / app.js / style.css・依存なしの静的ファイル）
stocknews/server.py: 127.0.0.1 だけで待ち受け、画面の配信・定期の取り直し・ウォッチの保存
```

カテゴリは書き出しのたびに判定し直します。`classify.py` の語句や `sources.json` の既定を直したら、
`python -m stocknews export` だけで反映されます（取り直し不要）。
